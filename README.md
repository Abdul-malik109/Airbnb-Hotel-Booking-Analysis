# Airbnb Hotel Booking Analysis

## Overview
This project focuses on analyzing Airbnb-style hotel and property booking data to uncover trends in pricing, customer behavior, availability, and booking outcomes. The primary objective is to perform Exploratory Data Analysis (EDA) and extract insights that can help hosts, travelers, and platform stakeholders make data-driven decisions.

The analysis examines how factors such as room type, pricing, length of stay, and seasonal trends influence booking success and cancellations.

---

## Dataset
- **Source**: Publicly available Airbnb / hotel booking dataset commonly used for analytical case studies.
- **Format**: CSV file loaded and processed within a Jupyter Notebook.
- **Key Features**:
  - Property / hotel type  
  - Room type  
  - Price per night  
  - Number of guests  
  - Length of stay  
  - Lead time  
  - Booking status (confirmed or canceled)  
  - Seasonal and availability indicators  

Missing values, duplicates, and inconsistent entries were handled during data preprocessing.

---

## Tools and Technologies
- **Programming Language**: Python  
- **Environment**: Jupyter Notebook  
- **Libraries**:
  - `pandas` – data manipulation and cleaning  
  - `numpy` – numerical operations  
  - `matplotlib` – data visualization  
  - `seaborn` – statistical data visualization  

---

## Analysis Workflow
1. **Data Loading**
   - Imported the dataset and inspected its structure and basic statistics.

2. **Data Cleaning & Preprocessing**
   - Handled missing values  
   - Corrected data types  
   - Removed duplicates and treated outliers  

3. **Exploratory Data Analysis (EDA)**
   - Analyzed price distribution and stay duration  
   - Compared booking behavior across room and property types  
   - Examined cancellation patterns  
   - Identified seasonal and demand-based trends  

4. **Visualization**
   - Histograms and boxplots for numerical variables  
   - Bar charts for categorical comparisons  
   - Trend analysis using time-based plots  

5. **Insight Extraction**
   - Identified key drivers affecting bookings and cancellations  

---
